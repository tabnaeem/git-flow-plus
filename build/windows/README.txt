Git Flow Plus
=============

Git Flow with enterprise release management: Sprint.Feature.ReleaseFix.
DevOps.QA versioning, mandatory release tagging, and a Feature Registry,
on top of the standard Git Flow branching model.

Getting started
---------------

Open a terminal (PowerShell, Git Bash, or Command Prompt) and run:

    git flow doctor
    git flow version
    git flow init

"git flow doctor" checks that Git is installed, that this install is
correctly on PATH, and that everything else needed to run Git Flow Plus
is healthy. "git flow init" sets up the main/staging/develop branches in
a repository.
